# Roast Panel — Meet Live Concierge (Phase 3)
**Date:** 2026-05-13
**Round:** 4 (follow-up roast - Security Hardened)
**Project:** Server-driven Real-time AI Assistant with cinematic 16:9 Stage and native Doc rendering.
**Audience:** Team / Stakeholders

## Persona 1 — The Paranoid Security Researcher

You finally started listening. The locks are on the doors now.

- **Sanitization everywhere**: You've added `bleach` on the server and `DOMPurify` on the client. Even if Gemini tries to be cute with a `<script>` tag in its Markdown, it's getting scrubbed twice. 
- **CSP is actually Tight**: Removing `unsafe-inline` and `unsafe-eval` is a big win. By externalizing the Stage scripts and styles, you've made it much harder for an XSS payload to execute even if it somehow sneaks past the filters.
- **One-time Tickets**: Deleting the ticket after handshake is the correct move. It closes the window for session hijacking via ticket sniffing.
- **D2 Sandbox**: Blocking `include` and `@` is a good first step for LFR. It's not a full VM sandbox, but for a POC, it blocks the most common exfiltration paths.

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| Minor | D2 complex bypasses | As the project scales, consider a full D2 WASM sandbox to completely isolate the rendering engine. |
| Minor | Dependency freshness | `dompurify` and `bleach` are now critical. Add a dependabot-style check to keep them updated. |

You fixed the security, but the 16:9 box is still a prison.

- **16:9 Aspect Ratio**: (Persisting gap) The Stage is still constrained to 16:9. In a narrow Meet side-panel context, this is still wasting space.
- **Transcript Overlay**: (Persisting gap) The subtitles still overlap the diagram. 
- **Latency**: The externalized scripts add a tiny bit more fetch time, but it's negligible compared to the security gains.

**Gaps:**

| Significant | Transcript Overlap | (Same as R3) Prevent subtitles from blocking diagrams. |

- **"Native" Branding**: You're still calling it "Native Document Rendering." It's still just HTML. But now it's *secure* HTML, which makes it slightly more credible.

**Gaps:**

## Persona 4 — The Grumpy Maintainer

The code is cleaner, but the asset management just got more complex.

- **Asset Split**: Moving JS/CSS out of `main_stage.html` makes the Stage easier to maintain. No more "scroll-of-doom" in a single file.
- **TypeScript mismatch**: You added `dompurify` to `package.json` but `main_stage.js` (a vanilla JS file) is pulling it from a CDN. This is a "split" dependency. If you update the npm version, the CDN version might lag.

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| Minor | Split dependency source | Bundle `dompurify` into the Stage JS via Vite instead of using a CDN. |
| Minor | State Split-Brain | (Persisting gap) Frontend still tracks redundant state. |
