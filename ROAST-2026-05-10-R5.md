# Roast Panel — Meet Live Concierge
**Date:** 2026-05-10
**Round:** 5 (follow-up)
**Project:** Google Meet AI Sidekick (Gemini Live + D2 Diagrams + Workspace Export)
**Audience:** Team / Open Source Demo

## Status Update
The **Critical** lack of testing and **Significant** CSP vulnerabilities have been **Fixed**. 
- A `pytest` suite now covers token validation.
- The `Content-Security-Policy` has been restricted to trusted Google domains.
- Sensitive logs have been sanitized.
- **New Feature**: Transcript Export is fully implemented and tested.

---

## Persona 1 — The Paranoid Security Researcher
"The backend is much tighter now. Token validation and the restricted CSP remove the low-hanging fruit. However, I noticed in `index.tsx` that we're still using `unsafe-eval` in the CSP for script-src. While GIS sometimes needs it, it's a permanent 'maybe' for XSS. Also, your `rsvg-convert` subprocess in `main.py` is called with SVG data directly from the in-memory store—if a user manages to inject a malicious SVG that exploits a buffer overflow in `librsvg`, they've got code execution in your container."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Minor** | `index.tsx` L372: Still requesting `chat.messages.readonly`. | Consider making this scope optional or explaining the need in the UI. |
| **Significant** | `main.py` L401: Subprocess call to `rsvg-convert` uses raw SVG bytes from memory without a size limit. | Implement a maximum byte size check for SVGs before passing them to the conversion subprocess. |

## Persona 2 — The Impatient UX Designer
"I'm actually impressed with the new 'Open Export' button in the Topbar. It makes the 'where did my file go?' problem vanish. But—and this is a big but—I am **still** hitting the **Activity Conflict**. If I have captions on and I try to start a diagram, nothing happens. I have to manually close the caption stage before the diagram will appear. This should be automated or at least explained."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | `index.tsx` L680: Activity conflicts (captions vs diagrams) still lack UI feedback. | Implement a `this.error` update when `startActivity` fails, specifically suggesting to close the current item. |
| **Minor** | UI Branding: 'Kore' still appears in the status bar while the assistant is listening. | Standardize 'Kore' to 'Gemini' or 'Assistant' for consistency. |

---

## Persona 3 — The Skeptical Credibility Critic
"You've addressed the security and added a great export feature, which makes the tool actually useful. However, your 'real-time diagrams' claim is still hanging by a thread because of that 5-second silence trigger. Also, why does the 'Export' button for transcripts look exactly like the 'Mode' toggles? Actions that save files should look distinct from switches that turn features on and off."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | Feature Branding: 'Kore' is a ghost in the machine. Users don't know who Kore is. | Replace 'Kore' with 'Gemini' or 'Assistant' in all status messages. |
| **Significant** | UI Consistency: The 'Export' button in the transcript header uses the `mode-toggle` class. | Use a distinct `action-btn` style for one-time commands vs state toggles. |

---

## Persona 4 — The Grumpy Maintainer
"Tests are passing, which is the highlight of my week. But we've just added 100+ lines to `main.py` for the export logic. The file is officially too big. And `index.tsx` is still an 1100-line monolith. If we want to add a third mode (like 'Mindmap'), this structure is going to snap. Also, your `tests/test_auth.py` is great, but we have zero tests for the `export_transcript` endpoint itself."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | `index.tsx`: Monolithic file structure. | Extract the `Render` logic or the `Transcript` section into its own component file. |
| **Significant** | `main.py`: Route bloat. | Move helper functions like `validate_google_token` and `_svg_to_png` into a `utils.py`. |
| **Minor** | Testing: `tests/test_auth.py` only covers one function. | Add a test for the `/api/transcript/export` endpoint using `httpx.ASGITransport`. |

## Panel Verdict

| Severity | Gap | Persona(s) | Fix direction |
|---|---|---|---|
