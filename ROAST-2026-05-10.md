# Roast Panel — Meet Live Concierge
**Date:** 2026-05-10
**Round:** 1 (first roast)
**Project:** Google Meet AI Sidekick (Gemini Live + D2 Diagrams + Workspace Export)
**Audience:** Team / Open Source Demo

---

## Persona 1 — The Paranoid Security Researcher

"Sending a raw OAuth `access_token` over a WebSocket to a Cloud Run backend that has no internal authentication? You've essentially built a proxy that turns any valid Meet token into a 'Create whatever you want in my Drive' pass. If that WebSocket is intercepted or the backend logs the payload on a crash, it's game over for the user's entire Workspace. Also, I see `allow_unauthenticated` in your deploy script. Bold move."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Critical** | `main.py` L420+: Backend accepts raw `access_token` over WebSocket with no signature or origin verification. | Use a backend-side session cookie or validate the token against a known client ID immediately on receipt. |
| **Significant** | `README.md` L88: Suggests `--allow-unauthenticated` for the Cloud Run service. | Remove this flag and use Google IAP or requiring authenticated invokes for the API endpoints. |
| **Significant** | `index.tsx` L370: Scopes requested include `drive` (full access) and `chat.messages.readonly`. | Narrow Drive scope to `drive.file` and only request Chat scopes if the feature is explicitly enabled. |

---

## Persona 2 — The Impatient UX Designer

"You're calling this a 'concierge', but the setup process is a 12-step pilgrimage through GCP Marketplace, Apps Script manifests, and manual ID substitutions. If I have to touch a `.clasp.json` just to see an AI talk, I've already quit. Also, your 'Another activity running' bug is a classic 'computer says no' moment—don't just log it to the console, tell me I need to close the current Doc first!"

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | `README.md` Setup: Requires manual `sed` commands and three different project IDs. | Create a `setup.sh` script or use a Terraform/Pulumi template to automate the GCP/Apps Script link. |
| **Significant** | `index.tsx` L680: Activity conflicts are logged as `console.warn` but the UI remains in a 'Connecting' or 'Off' state. | Catch `ActivityIsOngoing` errors and show a 'Please close the active stage item first' banner. |
| **Minor** | `index.tsx` Render: The 'v16' hardcoded version string is the only way to know if a deploy actually worked. | Replace with a dynamic build timestamp or git hash injected by Vite. |

---

## Persona 3 — The Skeptical Credibility Critic

"You call it 'Gemini Live concierge' in the topbar, 'Gemini Agent Architect' in the diagram section, and 'Kore' in the status messages. Pick a personality. Also, your 'real-time diagrams' are just static D2 snapshots triggered by 5 seconds of silence. If I stop to think, it generates a new diagram; if I keep talking, it does nothing. That's not real-time, that's an aggressive screenshot tool."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | `index.tsx` L108: Conflicting branding ("Gemini Live" vs "Agent Architect" vs "Kore"). | Centralize all naming in a `constants.ts` and use one consistent product name across UI and logs. |
| **Significant** | `plan.md`: The diagram feature is labeled 'Option 1 (snapshot)' but the UI presents it as a continuous mode. | Clearly label the button 'Diagram Snapshot' or implement a true diff-based update. |
| **Minor** | `README.md` Features: Claims 'Auto-Stage' for documents, but this often fails if the user isn't the one who initiated the activity. | Add a 'Join Active Activity' button for participants who miss the initial push. |

---

## Persona 4 — The Grumpy Maintainer

"Your `index.tsx` is an 1180-line junk drawer. CSS, HTML templates, WebSocket logic, AudioWorklet management, and OAuth flows are all fighting for space in one file. If the Meet SDK version bumps to 2.0, good luck finding every `startActivity` call. Also, installing the `d2` binary via `curl` in a `Dockerfile` is a recipe for a broken CI/CD pipeline the moment that URL changes."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | `index.tsx`: Monolithic file structure (1100+ lines). | Break into `components/`, `services/websocket.ts`, and `styles.ts`. |
| **Significant** | `Dockerfile` L4: Manual binary download for `d2`. | Use a multi-stage build with an official `d2` image if available, or pin the SHA256 of the downloaded tarball. |
| **Critical** | Workspace Root: Zero unit or integration tests for the frontend or backend. | Add `pytest` for the FastAPI endpoints and `uv_test` or `vitest` for the Lit components. |

---

## Panel Verdict

**Gaps by severity (cross-panel):**
| Severity | Gap | Persona(s) | Fix direction |
|---|---|---|---|
| **Critical** | Backend Token Proxy Risk | Security | Implement backend-side token validation. |
| **Critical** | Total lack of automated testing | Maintainer | Add `pytest` and `vitest` suites. |
| **Significant** | Activity Conflict Sync Bug | UX | Handle `ActivityIsOngoing` errors in UI. |
| **Significant** | Brand Identity Crisis | Critic | Unify "Concierge" vs "Architect" naming. |
| **Significant** | Monolithic Frontend Code | Maintainer | Refactor `index.tsx` into modules. |
| **Significant** | Complex Manual Onboarding | UX | Automate the GCP/Apps Script setup steps. |

**Exit criteria:**
- [ ] Implement backend token validation or IAP.
- [ ] Fix the "Another activity running" UI feedback.
- [ ] Unify branding to "Gemini Agent Architect".
- [ ] Add at least one end-to-end test for the `/api/diagram` endpoint.

**Recommended fix order:** Security (Critical) -> Testing (Critical) -> UI Sync (Significant) -> Branding (Significant) -> Refactoring (Significant).
