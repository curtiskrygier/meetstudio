# Roast Panel — Meet Live Concierge
**Date:** 2026-05-10
**Round:** 3 (follow-up)
**Project:** Google Meet AI Sidekick (Gemini Live + D2 Diagrams + Workspace Export)
**Audience:** Team / Open Source Demo

## Status Update
The **Critical** security risk regarding unvalidated access tokens has been **Fixed** and **Verified**. The backend now strictly validates every token against Google's `tokeninfo` endpoint and checks the Client ID audience. Drive permissions have been narrowed to `drive.file`. The **Export Transcript** feature is now fully functional with a dedicated UI button and backend support.

---

## Persona 1 — The Paranoid Security Researcher
"The token validation is solid now. You've significantly reduced the risk of the backend being used as a malicious proxy. However, I noticed in `main.py` that you're still printing `resp.text` on validation failures—if Google's error response ever echoes back part of the token, you're leaking secrets into your Cloud Run logs. Also, your `MeetFramingMiddleware` still has `default-src *` in its CSP. That's a massive XSS playground."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | `main.py` L610: CSP `default-src *` is far too permissive for a production-grade add-on. | Restrict CSP to specific allowed domains (`https://*.google.com`, etc.) and remove the wildcard. |
| **Minor** | `main.py` L618: Error logging potentially includes sensitive error details from Google. | Log only the status code and a generic error message, never the full raw response body. |

---

## Persona 2 — The Impatient UX Designer
"Security is nice, but I'm still hitting that **Activity Conflict** wall. If I have Captions on and I click 'Diagrams', nothing happens except a console warning that nobody sees. You've had three rounds to fix this! Also, your new 'Export' button is a plain text button—make it look like an action! And 'v16' in the corner? That's developer noise, not user signal."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** (Elevated) | `index.tsx` L680: Activity conflicts still have zero user-facing feedback. | Implement a 'Switching modes...' sequence that calls `endActivity()` or shows a 'Close current item' banner. |
| **Minor** | `index.tsx` L1182: The 'Export' button is just a `mode-toggle` class; it needs an icon to feel like a 'Save' action. | Add a 'download' or 'doc' icon to the Export button. |

---

## Persona 3 — The Skeptical Credibility Critic
"You've standardized the 'Gemini Agent Architect' branding in most places, but the orb still says 'Listening — Kore is ready'. Who is Kore? Why is she in my architecture meeting? Also, your 'real-time' claim in the README is still misleading since diagrams only generate when the room goes silent for 5 seconds. If we have a lively debate, the diagram never updates."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | Branding: 'Kore' still appears in status messages and the README. | Replace all remaining 'Kore' references with 'Gemini' or 'Architect'. |
| **Significant** | Feature Claim: 'Real-time diagrams' is technically false under the current silence-trigger implementation. | Update README to 'On-demand Diagrams' or implement a 'Generate Now' hotkey that doesn't wait for silence. |

---

## Persona 4 — The Grumpy Maintainer
"We're in Round 3 and there are **still no tests**. Not for the token validation, not for the new export endpoint, nothing. If you change one regex in your D2 parser, the whole thing could silently fail. Also, `main.py` is now a 1000-line monolith of its own. It's time to split the routes from the logic before this becomes unmanageable."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Critical** (Elevated) | Project Root: Total lack of automated testing persists. | Create a `tests/` folder and add `pytest` for the `validate_google_token` function immediately. |
| **Significant** | `main.py`: The file is becoming a 'God Object' containing config, helpers, and all API routes. | Split into `app/auth.py`, `app/routes.py`, and `app/diagrams.py`. |

---

## Panel Verdict

**Gaps by severity (cross-panel):**
| Severity | Gap | Persona(s) | Fix direction |
|---|---|---|---|
| **Critical** | Persistent Lack of Testing | Maintainer | Add `pytest` for backend logic. |
| **Significant** | Unhandled Activity Conflicts | UX | Implement `endActivity()` logic or UI banners. |
| **Significant** | Identity Crisis (Kore vs Gemini) | Critic | Remove the last 'Kore' references. |
| **Significant** | Permissive CSP | Security | Tighten `Content-Security-Policy` in middleware. |

**Exit criteria:**
- [x] Implement backend token validation.
- [ ] Add `pytest` for at least the `validate_google_token` helper.
- [ ] Implement UI feedback for activity conflicts.
- [ ] Standardize 'Kore' out of the UI.

**Recommended fix order:** Testing (Critical) -> Security (Significant) -> UX (Significant) -> Branding (Significant).
