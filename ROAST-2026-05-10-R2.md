# Roast Panel — Meet Live Concierge
**Date:** 2026-05-10
**Round:** 2 (follow-up)
**Project:** Google Meet AI Sidekick (Gemini Live + D2 Diagrams + Workspace Export)
**Audience:** Team / Open Source Demo

## Status Update
The **Critical** security risk regarding unvalidated access tokens has been **Fixed**. The backend now verifies all tokens against Google's `tokeninfo` endpoint. Drive permissions have been narrowed from full access to `drive.file`.

---

## Persona 1 — The Paranoid Security Researcher
"The token validation is a massive improvement. You've closed the open proxy hole. Using `tokeninfo` to check the audience (`aud`) against the `CLIENT_ID` is the right move. I'm still keeping an eye on those logs—ensure the `access_token` itself is never logged during validation failures."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | Deployment: `no-allow-unauthenticated` is a good start, but ensure the Cloud Run service account doesn't have over-privileged access to other GCP resources beyond Vertex AI. | Conduct an IAM audit of the Cloud Run service account. |

---

## Persona 2 — The Impatient UX Designer
"Still waiting for that 'Another activity running' fix. If I switch from Captions to Diagrams, the app still gets confused sometimes. Also, the new 'Export' button is great, but does it give me a link to the doc once it's done, or do I have to go hunting in Drive?"

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | `index.tsx` L680: Activity conflicts still lack proper user-facing error banners. | Implement a snackbar or banner that tells the user to manually close the active stage item. |
| **Significant** | Export UX: The status says 'Transcript exported to Drive ✓' but providing a direct 'Open Doc' link immediately would be much better. | Return the Doc URL from the export endpoint and show a 'View Doc' button in the status message. |

---

## Persona 3 — The Skeptical Credibility Critic
"You fixed the security, but the identity crisis remains. The status bar says 'Listening — Kore is ready' while the button says 'Gemini Agent Architect'. Is it an architect or a concierge? Pick one and stick to it."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | Conflicting branding in `index.tsx` and `main.py`. | Standardize all user-facing strings to 'Gemini Agent Architect'. |

---

## Persona 4 — The Grumpy Maintainer
"Security is better, but the codebase is still a monolith and there are still **zero tests**. You've added complex token validation logic—how do we know it actually works for expired tokens or wrong audiences without manually clicking through a Meet session?"

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Critical** | Still no automated tests. | Add `pytest` for the new `/api/transcript/export` and validation logic. |

---

## Panel Verdict

**Gaps by severity (cross-panel):**
| Severity | Gap | Persona(s) | Fix direction |
|---|---|---|---|
| **Critical** | Total lack of automated testing | Maintainer | Add `pytest` and `vitest` suites. |
| **Significant** | Activity Conflict Sync Bug | UX | Handle `ActivityIsOngoing` errors in UI. |
| **Significant** | Brand Identity Crisis | Critic | Unify naming to "Gemini Agent Architect". |
| **Significant** | Export UX: Missing direct link | UX | Return and display the Doc URL after export. |

**Exit criteria:**
- [x] Implement backend token validation.
- [ ] Fix the "Another activity running" UI feedback.
- [ ] Unify branding to "Gemini Agent Architect".
- [ ] Add at least one automated test for the validation logic.

**Recommended fix order:** Testing (Critical) -> UX (Significant) -> Branding (Significant).
