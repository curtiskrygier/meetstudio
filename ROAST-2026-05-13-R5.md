# Roast Panel — Meet Live Concierge
**Date:** 2026-05-13
**Round:** 5 (follow-up roast)
**Project:** Real-time AI Assistant with Architectural Diagramming for Google Meet
**Audience:** Team / Stakeholders

## Persona 1 — The Paranoid Security Researcher

You've finally stopped using `innerHTML` as a welcome mat for hackers. The double-layered sanitization (`bleach` + `DOMPurify`) is what I like to see.

- **CSP is Tight but Fragile**: You removed `unsafe-inline`, but now you're relying on a CDN (`cdnjs.cloudflare.com`) for `DOMPurify` on the stage. If that CDN is compromised or blocked, your Stage's security logic fails silently or breaks entirely.
- **D2 Blacklisting is a Cat-and-Mouse Game**: Blocking `include` and `@` is fine for a start, but sophisticated attackers will find a way to bypass your regex. You should be using the `--sandbox` flag if the `d2` binary supports it, or better yet, a dedicated D2-WASM runner that has no OS access.
- **One-time Tickets work**: Verified. The `pop()` in `main.py` ensures the ticket dies after the first handshake.

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| Significant | Split dependency source | Bundle `DOMPurify` into the Stage's assets via Vite instead of using a CDN. |
| Minor | D2 Sandbox | Research and implement a true sandbox (e.g., gVisor, WASM, or strict container isolation) for the `d2` binary. |

## Persona 2 — The Impatient UX Designer

You fixed the "Security" problem, but you're still ignoring the "Human" problem.

- **The 16:9 Prison**: I'm still seeing `aspect-ratio: 16 / 9` in `main_stage.css` (line 52). If I'm using Meet in a narrow side-panel, your diagram is a tiny rectangle with 60% black bars. It's "cinematic" for a movie, but it's a "failure" for a tool.
- **Subtitles vs. Content**: Your transcript container is still an overlay (`main_stage.css` line 118). When Gemini talks, the subtitles cover the bottom part of the diagram. I can't read the architecture while the assistant is explaining it.
- **Scrolling in a Box**: `max-height: 450px` on `markdown-body` (`main_stage.css` line 164). Why? If it's a document view, let the document take the space. Don't make me scroll a tiny window inside a window.

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| Significant | Aspect Ratio Friction | Remove the hard 16:9 constraint; use responsive flex layout to fill the available Stage space. |
| Significant | Transcript Overlap | Move the transcript to a dedicated letterbox/footer area that doesn't overlap the main content. |
| Minor | Scrolling Card | Remove the `max-height` on doc previews and let them breathe. |

## Persona 3 — The Skeptical Credibility Critic

You've made it safer, which adds credibility, but the feature gap is still there.

- **"Native Document Rendering" Branding**: You're still calling it "Native" in the README/Status. It's just a Markdown previewer. It's high-fidelity text, but it's not a "Native Doc." Call it "Real-time Previews" and you'll get less pushback from people who expect an actual Google Doc.
- **Legacy Stages are Litter**: Your `dist/` and `public/` folders are full of `diagram_stage.html` and `transcript_stage.html`. Are these used? If they are legacy, delete them. A "Production POC" shouldn't have ghost components.

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| Minor | Legacy Stage clutter | Delete `diagram_stage.html` and `transcript_stage.html` if the new `main_stage.html` handles both modes. |
| Minor | Branding | Update all mentions of "Native Rendering" to "Real-time Previews". |

---

## Persona 4 — The Grumpy Maintainer

The refactor is 90% there, but the last 10% is where the bugs live.

- **Redundant State Logic**: You have `diagramMode` and `audioEnabled` in `index.tsx` (Side Panel) AND `main.py` (`ui_state`). The Side Panel still tries to manage its own state instead of just rendering what the server tells it. This is how you get "out of sync" bugs.
- **Binary Fragility**: You're shelling out to `d2`. If that binary isn't in the Cloud Run PATH, the app crashes. You need a health check on startup that runs `d2 --version` and logs a critical error if it fails.
- **Duplicate Transcript Strings**: You're formatting "Gemini Architect" in `main_stage.js` and `index.tsx`. If you want to rebrand, you have to do it in two languages and two files.

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| Significant | State Split-Brain | Make `index.tsx` a "dumb" renderer for the `A2UI_STATE` sent by the server. |
| Minor | Lack of Binary Health Check | Add a startup check in `main.py` to verify `d2` availability. |
| Minor | Label duplication | Centralize role labels (Agent/User) in the server's websocket payload. |
