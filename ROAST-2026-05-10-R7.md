# Roast Panel — Meet Live Concierge
**Date:** 2026-05-10
**Round:** 7 (follow-up)
**Project:** Google Meet AI Sidekick (Gemini Live + D2 Diagrams + Workspace Export)
**Audience:** Team / Open Source Demo

## Status Update
The project has undergone a major transformation since Round 1. 
- **Performance**: Polling has been replaced by **WebSocket Pushes**, and rendering has moved to **server-side PNGs**, making the Main Stage feel instant and professional.
- **Security**: The "SVG Bomb" risk is mitigated by a **5MB size limit**, and the backend is hardened with **token validation** and a **strict CSP**.
- **UX**: The **"Stage occupied"** error message finally provides a solution to the activity conflict bug.
- **Branding**: "Kore" is gone; **"Gemini Agent Architect"** is the singular identity.

---

## Persona 1 — The Paranoid Security Researcher
"You've locked the doors and windows. Removing the raw SVG endpoint and implementing that 5MB cap on the conversion engine was the exact defensive depth I wanted. I'm also glad to see the `access_token` is no longer dumped into the logs on failure. My only remaining concern is that your `main.py` is still doing heavy `subprocess` lifting in the main request cycle—if the D2 engine hangs, it could still lead to a denial-of-service via worker exhaustion."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Minor** | `main.py` L401: `subprocess.run` for `rsvg-convert` uses a 15s timeout, which is safe, but it's not truly asynchronous. | Use `asyncio.create_subprocess_exec` to avoid blocking the FastAPI worker during high-res PNG conversion. |

## Persona 4 — The Grumpy Maintainer
"We have a test folder! I'm actually smiling. The `test_auth.py` is a great foundation. However, we've just moved a massive amount of complexity into `main.py`. It's a 1070-line file that handles WebSocket state, PNG conversion, Drive folder creation, and OAuth validation. If a bug happens in the Drive logic, it shouldn't be able to crash the WebSocket handler."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | `main.py` Architecture: Single-file monolith. | Refactor the Drive and SVG/PNG conversion logic into a `services/` directory. |
| **Minor** | `index.tsx` CSS: 250+ lines of styles are cluttering the component logic. | Extract styles into an `index.css.ts` using Lit's `css` tag for better readability. |
