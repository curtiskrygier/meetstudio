# Roast Panel — Meet Live Concierge
**Date:** 2026-05-11
**Round:** 9 (follow-up)
**Project:** Google Meet AI Sidekick (Gemini Live + D2 Diagrams + Workspace Export)
**Audience:** Team / Open Source Demo

## Status Update
The "Killer Feature Upgrade" is live. 
- **UX**: Implemented **Image Preloading** to kill flickers, **WebSocket Push** for instant sharing, and **Auto-Open** for Drive exports. 
- **Layout**: Adjusted the Main Stage to ensure subtitles never obstruct diagrams.
- **Branding**: PURGED all "Kore" references.
- **Security**: Fixed the CSP `gstatic.com` bug and implemented multi-audience token validation.

---

## Persona 1 — The Paranoid Security Researcher

"The code-level security is finally in a professional state. Token validation against both the Web and Marketplace Client IDs is exactly what I was looking for. However, your 'Auto-Open' feature for exports relies on `window.open`. While functionally convenient, you're one browser update away from having your entire export flow silenced by a popup blocker. Also, I'm still seeing `unsafe-eval` in that CSP—it's a necessary evil for some Google SDKs, but it remains a permanent asterisk on your security audit."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Minor** | `main.py` L31: `MARKETPLACE_CLIENT_ID` is hardcoded. | Move all Client IDs to an environment variable `ALLOWED_CLIENT_IDS` (comma-separated). |

---

## Persona 2 — The Impatient UX Designer

"The 'Auto-Open' and 'Flicker-Free' updates are massive wins. It finally feels like an app, not a science experiment. But let's talk about the 'What can I say?' section. It's a static list in the middle of the body. If I'm scrolling through a long transcript, I lose that guidance. It should be a persistent 'Help' icon in the Topbar that opens a drawer or modal."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Minor** | `index.tsx`: Help section is buried in the scrollable body. | Move the voice command examples to a Topbar '?' icon menu or a persistent footer. |
| **Minor** | `index.tsx`: The 'Auto-Open' popup is often blocked. | Add a 'Link ready! [Open]' toast notification in addition to the `window.open` call. |

---

## Persona 3 — The Skeptical Credibility Critic

"You've nailed the branding and the performance. My only remaining 'jaded engineer' question is about the 'Save & New' feature. It does a lot of heavy lifting—saves the old one, clears the state, starts a new session, and broadcasts. If the 'Save' part fails (e.g. Drive quota hit), does it still wipe my current diagram? You might be deleting user work on a network error."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** | `index.tsx` L887: `saveAndNewDiagram` calls `saveDiagramToDrive` but doesn't await/check success before resetting state. | Ensure 'Save' succeeds before clearing the local diagram context. |

---

## Persona 4 — The Grumpy Maintainer

"The user-facing side is shiny, but the engine room is a disaster. `main.py` is still 1085 lines of unorganized logic. You've got WebSocket message types, SVG-to-PNG conversion, and Drive API calls all sitting in the same file. If a junior dev joins this project, they'll break the WebSocket heart just trying to update a CSS class in the SVG renderer. Refactor or die."

**Gaps:**
| Severity | Problem | Fix direction |
|---|---|---|
| **Significant** (Elevated) | `main.py`: The technical debt is now the single biggest risk to the project's longevity. | Extract the `/api/diagram` logic into a separate file this turn. |

---

## Panel Verdict

**Gaps by severity (cross-panel):**
| Severity | Gap | Persona(s) | Fix direction |
|---|---|---|---|
| **Significant** | Data Loss Risk in 'Save & New' | Critic | Check Save success before resetting context. |
| **Significant** | Code Monolith technical debt | Maintainer | Modularize the backend into services. |
| **Minor** | Hardcoded Marketplace ID | Security | Move all allowed IDs to environment variables. |
| **Minor** | Buried Help UI | UX | Move guidance to a persistent Topbar icon. |

**Exit criteria:**
- [x] Implement image preloading.
- [x] Implement WebSocket Push.
- [ ] Refactor `main.py` (Move diagram logic to `diagrams.py`).
- [ ] Fix the `saveAndNewDiagram` race condition.

**Recommended fix order:** 'Save & New' safety (Significant/Quick) -> Modularization (Significant/Debt) -> Help UI (Minor).
